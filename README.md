# supermemory

A team knowledge layer over a git-synced Obsidian vault: a local MCP server that
gives AI agents structured, validated, searchable access to a git-synced
Markdown knowledge vault. Full specification: [docs/RFC.md](docs/RFC.md).

> Note: `.atl/` is machine-local (auto-generated state with machine-specific
> paths) and stays gitignored — it is not part of the source.
