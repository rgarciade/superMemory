Conventions:
- Strict TDD (config.yaml): every code task runs RED → GREEN → REFACTOR — the failing test lands before the implementation. One work unit = code + tests + one conventional commit, tests green before every commit.
- Tests live with the code they test (`test/<module>/*.test.ts`); capabilities tagged `[project-config]` `[boot-validation]` `[sync-ladder]`.
- Each task is completable in one focused session. Pinned bytes (§4 of design) are asserted byte-exact wherever named.
- **Seam rule (design §6)**: `basePath`/`homeDir` are injected parameters; `process.cwd()`/`os.homedir()` appear only in commander action handlers and `serveVault`'s documented default. No test chdirs; no test mutates `process.env` for discovery.
